# React Axios Data Fetching Example

This example demonstrates how to perform data fetching using the Axios library within a React functional component. It utilizes React's `useState` and `useEffect` hooks to manage loading, error, and data states, making a GET request to a public API (JSONPlaceholder) when the component mounts. The fetched data, along with loading and error messages, is then displayed on the page.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
